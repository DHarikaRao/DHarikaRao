## Featured project

### [multi-document-rag](https://github.com/DHarikaRao/multi-document-rag)

Local question answering over PDFs with page-level sources. Runs fully offline with LangChain, ChromaDB, Hugging Face embeddings and Llama 3 (Ollama).

- **Hybrid retrieval:** vector search + BM25 keyword search, merged with Reciprocal Rank Fusion
- **Evaluation harness:** compares chunk sizes, `k` and search modes on a 13-question test set; hybrid search raised the retrieval hit rate from 80% to 100% at chunk size 1000
- **Documented limitations:** the README lists known failures, such as acronym questions, and next steps
- **Engineering basics:** reproducible setup, demo data fetched from arXiv, CI syntax check
